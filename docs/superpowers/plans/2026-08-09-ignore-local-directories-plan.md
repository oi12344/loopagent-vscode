# 本地目录不提交实施计划

## 目标

完成 6 个本地目录的 Git 索引清理，并确保后续默认不会再次进入提交。

## 步骤

- [x] 核对当前分支、工作区已有改动和目标目录的跟踪文件。
- [x] 在根目录 `.gitignore` 添加 6 条目录规则。
- [x] 使用 `git rm -r --cached` 移除目标目录的 Git 索引项，保留磁盘文件。
- [x] 运行忽略、索引、差异和状态检查。

## 验收

目标目录不再出现在 `git ls-files` 输出中；同名本地文件由 `git check-ignore` 命中；`blog/`、CodeGraph 数据库及 WAL/SHM 等既有改动保持原状。
