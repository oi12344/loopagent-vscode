# Webview 消息窗口设计

## 目标

当对话历史或单次运行的过程事件过多时，保持 LoopAgent Webview 可交互，避免一次性为全部历史内容和过程步骤建立可见 DOM。

## 范围

- 保留完整消息状态和持久化数据，不改变模型上下文。
- 聊天区只渲染最近 80 条消息，并显示隐藏提示。
- 单次助手过程只渲染最近 40 个步骤，摘要仍显示完整步骤总数。
- 使用 `React.memo` 避免流式更新时重新计算未变化的历史消息。

## 取舍

当前不引入虚拟列表依赖，也不改动消息协议或存储结构。窗口边界固定且可读，后续若需要浏览全部历史，再增加按滚动加载，而不是把所有内容重新放回首屏 DOM。

## 验证

- `test/App.test.tsx` 覆盖大量恢复消息和大量过程步骤。
- 运行 `npm.cmd test -- --run test/App.test.tsx`、`npm.cmd run typecheck` 和 `git diff --check`。
